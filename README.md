# onlineshopde.de

Statische Unternehmenswebsite von **onlineshopde – Schnellversand** (Onlinehandel Özlem Karabulut, Pforzheim).

- Reines HTML/CSS, kein JavaScript, keine Cookies, keine externen Ressourcen
- Schriften lokal eingebunden (Newsreader, IBM Plex Sans – SIL Open Font License 1.1, Lizenztexte in `assets/fonts/`)
- Hosting: GitHub Pages, Domain: www.onlineshopde.de

## Struktur

| Datei | Inhalt |
|---|---|
| `index.html` | Startseite |
| `kundenservice.html` | Kundenservice für Amazon- und eBay-Bestellungen |
| `impressum.html` | Impressum (§ 5 DDG) |
| `datenschutz.html` | Datenschutzerklärung |
| `404.html` | Fehlerseite |
| `assets/css/style.css` | Gestaltung (Farben und Abstände als CSS-Variablen in `:root`) |
| `robots.txt`, `sitemap.xml` | Suchmaschinen |

## Pflege

Texte direkt in den HTML-Dateien ändern. Bei Änderungen an der technischen Umsetzung (z. B. neue externe Dienste, Formulare, Statistik) muss die Datenschutzerklärung angepasst werden.
